BSIT Developer Portfolio

A responsive, modern, and interactive personal developer portfolio built for a 3rd-year Bachelor of Science in Information Technology (BSIT) student. Designed with a sleek dark-slate and royal-purple aesthetic, featuring live profile persistence, smooth navigation, and **three fully functional web systems** embedded directly into the project.


 Features

- **Responsive Single-Page Layout**: Built with Tailwind CSS, featuring smooth scrolling and mobile-friendly navigation.
- **Interactive Profile Photo**: Supports local photo uploading with browser `localStorage` persistence.
- **Built-In Live Systems**: Explore three complete mini-systems right inside the portfolio:
  1. **Campus Queue & Transaction System**: Issue queue tickets with Priority Lane sorting and real-time counter updates.
  2. **College GWA Calculator & Subject Tracker**: Philippine college grading scale (1.00–5.00) with automatic weighted GWA computation.
  3. **Tech Hub POS & Inventory System**: Product catalog, shopping cart, live warehouse stock deduction, and official receipt generator.


 Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript (ES6+)
- **Design & UI**: Custom glassmorphism cards, Google Fonts (Inter & JetBrains Mono)
- **Deployment Ready**: Pure client-side single-file architecture (`index.html`) optimized for GitHub Pages.


Quick Start & Deployment

1. Clone or download this repository.
2. Ensure your file is named **`index.html`**.
3. Place your profile picture in the folder and name it **`profile.jpg`** (or upload it directly via the portfolio UI).
4. Push to your GitHub repository and enable **GitHub Pages** under repository settings (`Settings` > `Pages` > Deploy from `main` branch).
